# Study Companion

面向学习者的智能体技能：在对话中讲解知识、整理主题笔记、记录易混点，并通过主动回忆和复习安排帮助学习者巩固。

## 它能做什么

- 识别讲解、提问、练习和复习等学习场景。
- 先解答当前问题，再把值得保留的内容整理到主题笔记。
- 建立概念之间的联系，区分已掌握、待巩固和易混淆的内容。
- 通过先回忆、后反馈的问答检查理解。
- 在学习者启用复习计划后，维护复习队列和下次复习日期。
- 使用学习者选择的语言、文件格式和笔记目录。

它不会把整段聊天原样存档，也不会把“听过讲解”当成“已经掌握”。是否记录由学习者控制；首次学习某个主题时会询问，获得同意后可在该主题后续学习中自动维护笔记。

## 使用

将目录 study-companion 作为 Agent Skill 安装到支持 SKILL.md 的智能体环境中。让智能体在学习主题时使用 study-companion，之后直接提问、要求练习或复习即可。

学习者可以在对话或工作区说明中指定：

- 笔记的保存目录和格式，例如 Markdown 或 LaTeX；
- 是否自动整理笔记；
- 是否启用主动回忆和复习队列；
- 复习频率、语言和解释深度。

## 文件

- study-companion/SKILL.md：技能指令与学习工作流。
- study-companion/agents/openai.yaml：Codex 的显示名称与调用提示。

## 隐私

技能只指导智能体在本地可写的学习工作区维护学习资料。它不要求上传或分享笔记，也不应保存密码、密钥等敏感信息。使用前请检查所用智能体的文件访问范围和工具权限。
